# CellCancer

The Stage 1 BCCD → YOLOv8n white-blood-cell localization project is in [leukemia-yolo](leukemia-yolo/README.md). It includes the Windows Conda setup, eight Jupyter notebooks, reusable Python modules, CLI commands and synthetic tests.

Stage 1 locates WBCs in blood-smear images. It does not diagnose leukemia or classify blasts.
